
# Papelería React Native

Aplicación móvil para la gestión de una papelería.

## Dominio
Papelería

## Entidades principales
- Products
- Stock
- Sales
- Customers

## Objetivo
Desarrollar una aplicación móvil que permita gestionar productos, inventario, ventas y clientes de una papelería.

## Desarrollo
El proyecto se construirá progresivamente, siguiendo las semanas del bootcamp bc-reactnative.

## Estado
En desarrollo.
